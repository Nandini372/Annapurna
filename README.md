# Annapurna – Food Donation & Distribution Platform

## Overview

Annapurna is a web-based platform designed to reduce food wastage by connecting food donors with NGOs, organizations, and individuals in need. The platform enables efficient food donation, management, and distribution through a simple and user-friendly interface.

## Features

* Food donation listing and management
* Donor and recipient registration
* Real-time food availability tracking
* Donation activity dashboard
* Responsive and mobile-friendly design

## Technologies Used

* React.js
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* React Query
* React Router DOM
* Recharts

## Installation

```bash
npm install
npm run dev
```

## Use Cases

* Restaurants donating surplus food
* NGOs identifying available donations
* Event organizers sharing leftover food
* Community-driven food distribution
